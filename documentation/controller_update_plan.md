# План обновления уровней в Minerals Platformer

## Цель
Интегрировать новую систему контроллеров уровней во все существующие уровни и обеспечить единообразие в управлении состоянием уровней.

## Шаги по обновлению

### 1. Создание резервных копий (ответственный: разработчик)
- Создать резервные копии всех сцен уровней перед изменениями
- Сохранить копии в папке `backup_scenes`

### 2. Обновление уровня 0 (ответственный: разработчик)
- Открыть сцену `scenes/level_0.tscn`
- Добавить сцену `scenes/level_0_controller.tscn` как Instance
- Убедиться, что контроллер находится в корне сцены
- Протестировать уровень, удостоверившись что:
  - Профессор корректно появляется на уровне
  - Подсказки отображаются правильно

### 3. Обновление уровня 1 (ответственный: дизайнер)
- Открыть сцену `scenes/level_1.tscn`
- Добавить сцену `scenes/level_1_controller.tscn` как Instance
- Убедиться, что параметр `is_dark_level` установлен в `true`
- Проверить работу тёмного режима и подсказок о кристалле

### 4. Обновление уровня 2 (ответственный: дизайнер)
- Открыть сцену `scenes/level_2.tscn`
- Добавить сцену `scenes/level_2_controller.tscn` как Instance
- Убедиться, что параметр `is_dark_level` установлен в соответствии с дизайном уровня
- Проверить подсчёт минералов и отображение подсказок

### 5. Обновление уровня 3 (ответственный: программист)
- Открыть сцену `scenes/level_3.tscn`
- Добавить сцену `scenes/level_3_controller.tscn` как Instance
- Проверить наличие движущихся платформ и добавить их в группу "moving_platform"
- Проверить работу таймера подсказок

### 6. Тестирование прохождения (ответственный: тестировщик)
- Протестировать прохождение всей игры
- Убедиться, что переходы между уровнями работают корректно
- Проверить сохранение прогресса между уровнями
- Убедиться, что темный режим и освещение работают согласованно

### 7. Оптимизация (ответственный: программист)
- Проверить производительность
- Устранить возможные утечки памяти
- Оптимизировать код контроллеров при необходимости

## Критерии успеха
- Все уровни используют новую систему контроллеров
- Контроллеры правильно управляют состоянием уровней
- Нет регрессий в функциональности
- Производительность не ухудшилась
