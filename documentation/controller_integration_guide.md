# Руководство по интеграции контроллеров уровней

## Обзор
В этом руководстве описывается процесс интеграции системы контроллеров уровней в сцены уровней.

## Шаги по интеграции

### 1. Базовая интеграция (для существующих уровней)

Чтобы добавить контроллер к существующему уровню:

1. Откройте сцену уровня (например, `level_1.tscn`)
2. Добавьте соответствующую сцену контроллера как Instance:
   - Выберите меню "Scene" -> "Instance Child Scene" 
   - Выберите соответствующий контроллер:
     - `scenes/level_controller.tscn` для стандартных уровней
     - `scenes/level_0_controller.tscn` для нулевого уровня
     - `scenes/level_1_controller.tscn` для первого уровня
     - `scenes/level_2_controller.tscn` для второго уровня
     - `scenes/level_3_controller.tscn` для третьего уровня
3. Убедитесь, что контроллер добавлен как дочерний узел корневого узла уровня

### 2. Создание нового уровня с контроллером

При создании нового уровня:

1. Создайте новую сцену с корневым узлом `Node2D`
2. Добавьте сцену контроллера как Instance (см. шаги выше)
3. Продолжайте создание уровня, добавляя тайлмапы, объекты и т.д.

### 3. Параметры контроллера

Каждый контроллер имеет настраиваемые параметры, доступные в инспекторе:

- `show_lives` - показывать ли счетчик жизней на UI
- `is_dark_level` - является ли уровень темным

Установите эти параметры в соответствии с требованиями уровня.

### 4. Создание специализированного контроллера

Если для уровня требуется уникальная логика:

1. Создайте новый скрипт, наследующийся от `BaseLevelController`:
   ```gdscript
   extends BaseLevelController
   
   # Переопределение метода инициализации уровня
   func _level_specific_setup():
       # Ваша специфическая логика здесь
       pass
   ```

2. Создайте сцену контроллера с этим скриптом:
   - Создайте новую сцену с корневым узлом `Node`
   - Назначьте ему ваш скрипт
   - Сохраните сцену, например, как `level_custom_controller.tscn`

3. Интегрируйте в уровень как обычно

## Проверка работы контроллера

Чтобы убедиться, что контроллер уровня работает корректно:

1. Запустите уровень
2. Проверьте консоль на наличие отладочных сообщений от контроллера
3. Проверьте, работают ли все функции, которые должен обеспечивать контроллер (темный режим, подсказки и т.д.)

## Примечания

- Каждый уровень должен иметь ровно один контроллер
- Контроллер должен быть добавлен в группу "level_controller" (это делается автоматически в методе `_ready()`)
- При возникновении проблем убедитесь, что скрипт базового контроллера (`base_level_controller.gd`) доступен в проекте и правильно импортирован
